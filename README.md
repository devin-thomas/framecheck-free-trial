# FrameCheck Beta

FrameCheck is a browser-local fighting-game assessment prototype. This clean-room public repository is being assembled as an employer-facing vertical slice.

## Development

Requires Node.js 24 and npm 11.

```bash
npm ci
npm run dev
```

Quality checks are available through `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.

Unofficial demonstration content. No affiliation with or endorsement by any game publisher.
